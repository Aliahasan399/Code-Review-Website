✦ FAQ

Common questions

Everything you need to know about Code Review Website.

What languages are supported?

16 languages: JavaScript, TypeScript, Python, HTML, CSS, Java, C++, C#, Go, Rust, PHP, Ruby, Swift, Kotlin, Bash — plus Auto Detect.

Is it really free?

Yes! All static analysis features are completely free. AI-enhanced suggestions are also free with no limits.

How is the score calculated?

Starting from 100, we deduct points: -15 per error, -8 per warning, -3 per info. The final score ranges from 10-100.

What categories are checked?

Security, Syntax & Structure, Performance, Code Style, and Best Practices — each with its own score and detailed issues.
